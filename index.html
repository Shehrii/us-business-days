US federal holidays 2026 to 2030, with observed dates

The eleven federal holidays set by 5 U.S.C. 6103(a). When a holiday falls on a Saturday, federal employees get the Friday before off; when it falls on a Sunday, the Monday after (OPM rule). The "Day off" column shows that observed date.

Count business days

To add or count working days around these holidays without code, use the business days calculator or days between dates on Dates Ahead, which run the same rules.

Data and code

Every holiday from 2020 to 2040 is in federal-holidays-2020-2040.json. The us-business-days repository also has a dependency-free JavaScript file with addBusinessDays and businessDaysBetween. MIT licence.

Not included: Inauguration Day (Washington DC area only), state holidays, and extra days off granted by executive order. Juneteenth is counted from 2021, the year it became a federal holiday.
